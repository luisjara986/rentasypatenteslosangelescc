# Sistema de Registro y Fiscalización de Comerciantes
### Sección de Rentas y Patentes — I. Municipalidad de Los Ángeles

Esta es la aplicación web/PWA ejecutable completa para la fiscalización de comerciantes ambulantes y patentes municipales de Los Ángeles.

## Contenido del Archivo ZIP:
1. `index.html` - Código completo de la aplicación (Web, Móvil, PWA e Impresión).
2. `manifest.json` - Configuración para instalación PWA en Smartphones (Android e iOS).
3. `README.md` - Instrucciones de uso e instalación.

## Cómo ejecutar la aplicación:
1. Extrae los archivos del ZIP en una carpeta local o servidora.
2. Abre `index.html` directamente en cualquier navegador (Google Chrome, Safari, Microsoft Edge, Firefox).
3. ¡Listo! Funciona de manera autónoma sin necesidad de instalar bases de datos externas adicionales.

## Características Incluidas:
- **Identificación Institucional:** Escudo oficial de Los Ángeles y membrete de la Sección de Rentas y Patentes.
- **Escáner QR y Búsqueda por RUT:** Verificación instantánea con cámara en terreno.
- **Historial de Fiscalizaciones (Hoja de Vida):** Registro inmutable con fecha, hora, inspector y observaciones.
- **Generación de Reportes / Actas Imprimibles:** Formato oficial listo para PDF o impresión física.
- **Administración de Usuarios y Roles:** Control de permisos y cambio seguro de contraseña.
- **Compatibilidad PWA Móvil:** Se puede instalar directamente en la pantalla de inicio de teléfonos celulares Android e iPhone.
